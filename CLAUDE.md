# CLAUDE.md

This file provides guidance to Claude Code when working with code in
this repository.

## Code style

- Comment blocks of logic, not every line. Explain the “why” of a
  section, not the obvious.
- No blank line between every statement (after a group of commands);
  group related lines, separate logical blocks.

## Answers

- Be concise: ~3 sentences per point.
- Answer only what’s asked; don’t explain multiple things at once.
- When asked about something, don’t try to create or modify code, just
  answer.
- Code/modify code when asked to do so.
