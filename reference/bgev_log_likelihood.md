# Log-likelihood function for the BGEV distribution

Log-likelihood function for the BGEV distribution

## Usage

``` r
bgev_log_likelihood(x, pars)
```

## Arguments

- x:

  Numeric vector of observations.

- pars:

  Vector of parameters (mu, sigma, xi, delta). See
  [bgev](https://thiagodoregosousa.github.io/bgev/reference/bgev.md).

## Value

The log-likelihood value.
