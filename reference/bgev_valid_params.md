# Validate BGEV parameters

Check if the provided parameters for the BGEV distribution are valid.

## Usage

``` r
bgev_valid_params(mu, sigma, xi, delta)
```

## Arguments

- mu:

  location parameter, as in
  [bgev](https://thiagodoregosousa.github.io/bgev/reference/bgev.md)

- sigma:

  scale parameter (sigma \> 0), as in
  [bgev](https://thiagodoregosousa.github.io/bgev/reference/bgev.md)

- xi:

  shape parameter in R, as in
  [bgev](https://thiagodoregosousa.github.io/bgev/reference/bgev.md)

- delta:

  shape parameter (delta \> -1), as in
  [bgev](https://thiagodoregosousa.github.io/bgev/reference/bgev.md)
